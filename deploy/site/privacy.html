Last updated 23 November 2026

{{APP_NAME}} is a small automation that receives enquiries sent through a salon website's contact form, drafts a suggested reply, and notifies the person who looks after the enquiries. It is operated by Nephtally Moshabeshe as a pilot. It is not a product offered to the public, and only the operator's own Google account signs in to it.

Google data this app uses

The app asks for three Google permissions and uses each only as described:

PermissionUsed for
Send email (gmail.send)Sending one notification email per enquiry to the operator's own inbox. The app cannot read, search or delete mail.
Google Sheets (spreadsheets)Adding one row per enquiry to a single log sheet owned by the operator.
Calendar free/busy (calendar.freebusy)Seeing which times are busy or free in the salon's booking calendar, so a reply can suggest open times. It can't see event titles, guests or details.

Google user data is not sold, shared with advertisers, or used to train AI models. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Enquiry data (website visitors)

When someone submits the contact form, the app receives the name, email, phone number, chosen service, preferred date and message they typed, plus their consent to be contacted. This is used only to answer that enquiry.

  • The message is sent to Anthropic's Claude API to classify it and draft a reply. Anthropic does not use API data to train its models.
  • The enquiry and the draft are stored in the operator's Google Sheet and in the automation server's run history.
  • Run history on the server is deleted automatically after 30 days.
  • Data is processed by these providers, some outside South Africa: Google, Anthropic, Vercel (website), and Oracle Cloud (automation server, Johannesburg).
